# 💇 Salon App

A full-stack salon management and appointment booking application built with React and JavaScript.

The application provides a complete salon experience for customers and salon staff, including service browsing, appointment booking, customer management, staff management, reviews, notifications, and payments.

## ✨ Features

### 👤 Customer Features

* User registration and login
* Customer profile management
* Browse salon services
* View service details
* Book appointments
* View appointments
* Change password
* Forgot password functionality
* Submit ratings and reviews
* Contact and location information

### 💼 Salon Management

* Dashboard
* Customer management
* Appointment management
* Staff management
* Service management
* Payment handling
* Reviews and ratings
* Notifications

### 💇 Services

The application includes multiple salon service categories such as:

* Hair styling
* Hair spa
* Facial
* Skincare
* Nail design
* Bridal services
* Offers and packages

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/krups128/salon-app.git
cd salon-app
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Start the frontend

```bash
npm start
```

### 4. Backend

Open a separate terminal, navigate to the backend directory, install the required dependencies, and start the backend according to the project's configuration.

> Make sure your database and environment configuration are set up before starting the application.
